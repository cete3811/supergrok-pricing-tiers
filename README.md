## 每一档月费实际买到什么

### Free：能用，但两小时就见底

免费版在官网和 X 里都能用，搭载较轻的模型，大约每 2 小时 10 次提问，附带基础的实时网络和 X 搜索。当作试用没问题，当作日常工具，两小时的计量器很快见底。

### SuperGrok Lite：$10 的过渡档

2026 年 3 月上线的入门付费档，比免费版宽松一些，附带 Grok Imagine 图像生成和一个基础智能体。适合每周只用几次、以文字对话为主的用户。如果已经每天都要用，或者会认真生成图片，这档的每周额度会偏紧。

### SuperGrok：$30，多数人真正的选择

标准档随更新搭载 Grok 4.6 模型，包含 Expert 搜索模式、图像和视频生成、Connectors、自定义智能体和 Skills，额度比 Free 和 Lite 高一截。行业里主流 AI 订阅的标准付费档大多停在 $20，SuperGrok 定在 $30，多出来的 $10 主要买实时 X 数据流——这一点目前没有直接竞品能对上。

### SuperGrok Plus：$100，为“撞限额”的人准备

和标准档跑同一个模型，功能一项不少。多出来的钱买的是额度：1080p 视频生成、Chat/Imagine/Voice/Build 各项用量大幅上调、响应更快、高峰期排队优先。升级的触发条件是用量，不是功能——如果你在标准档经常碰到限额、需要 1080p 视频、或者高峰时段等不起，这档就是为此设计的。反过来，偶尔聊聊天、出几张图的人，多付 $70 大概率买来一堆用不完的余量。

### SuperGrok Heavy：$300，买吞吐不买智商

Heavy 是自购档位的天花板，$300/月，围绕多智能体推理模式构建，渲染量更高，新模型最早体验。但要清楚一点：多出来的 $270 买的是并行和吞吐量，回答的聪明程度和 $30 档是一样的。已有 Heavy 订阅者反馈过高强度干活时一天烧完一整周额度，所以它也不是限额的逃生门。这是给多智能体工作流和研究场景用的专用工具，不是“更好的日常聊天”。

## 2026 年年中之后，$30 一个月能干的事变少了

这部分直接影响你对月费的判断。2026 年 6 月起，xAI 取消了各产品分开的每日限额，改成**一个共享的每周用量池**：聊天、图像、视频、语音全部从同一个池子里扣。

从已公开的实测汇总看，大致消耗是：一条 10 秒 720p 视频约占整周额度的 2%，480p 视频占 0.5%–1%，五六条短消息约占 1%–2%。换算下来，$30 档一整周大约能换 50 条 720p 视频，或者五六个小时的聊天。和改版前的每日限额相比，实际生成容量缩水了八成以上。

有三个隐性扣费点值得提前知道：

1. 被审核拦截的生成照扣额度。有用户反馈连续 20 次生成全被自动审核拦下、一张图没拿到，额度照样扣完然后被锁。
2. 把 480p 放大到 720p 要重新扣额度，不会复用你已经花掉的部分。
3. 有订阅者反映额度在没有任何操作的情况下夜间自己上涨（比如从 30% 跳到 67%），普遍猜测和动态公平使用机制有关，xAI 没有确认过原因。

每周额度的重置时间因人而异，在 Settings → Usage 里能看到已用百分比和下次重置日期。额度用完不会封号，付费功能暂停，免费的聊天和语音还能继续用。

另外，官方提供从 $5 起的额外用量点数，但有用户反馈充值后生成功能依然被锁，点数似乎只对 API 或 Build 生效。如果你的目的是解锁生成，充值前别想当然。

**SuperGrok 月费会再变吗？**
2026 年已经变过多次（新增 Plus、调整用量规则），订阅前以官方定价页当时显示为准。

**SuperGrok 和 SuperGrok Plus 到底差在哪？**
同一个模型，差在额度：Plus 多出 1080p 视频、大幅上调的用量、更快响应和高峰期优先。

**每周额度什么时候重置？**

**X Premium+ 是不是更便宜的 SuperGrok？**
不是。它 $40/月，比 SuperGrok 的 $30 还贵，捆绑的 Grok 用量上限却低于任何独立 SuperGrok 档。
